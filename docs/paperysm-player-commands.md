# PaperYSM 玩家命令

普通玩家只需要这个命令：

```text
/ysm sync
```

用途：

- 重新同步服务器模型列表和模型缓存。
- 刚进服没有自动刷出模型时执行一次。
- 换电脑、清过客户端 YSM/OpenYSM 缓存、服务器刚新增模型后执行一次。

原版 YSM/OpenYSM 命令仍可用：

```text
/ysm ping
/ysm auth
/ysm model
/ysm play
/ysm molang
/ysmclient debug
/ysmclient molang
/ysmclient watch
```

说明：

- `/ysm sync` 是 PaperYSM 的服务器同步命令。
- `/ysm model`、`/ysm play` 等是兼容原版 YSM/OpenYSM 的命令。
- 管理命令不对普通玩家开放。
